KAIDON'S BOT — ANDROID STARTER

This is a small installable-web-app prototype, not a finished native APK 

WHAT WORKS NOW
- Black and neon green chat interface
- .help, .joke, .quiz and .rules commands
- Saves chat history locally on this device
- Offline cache after it has been hosted and opened once

WHAT IS NOT CONNECTED YET
- General AI answers
- AI image generation
- Live music search / audio delivery
- Automatic reading or replying inside WhatsApp groups

WHY
Online AI and image generation need a secure server connection. API keys must never be placed in the app or shared in chat. A proper backend and hosting setup are needed. New AI image generation and live online services cannot work with no internet. Offline AI would need a suitable model downloaded to the phone and enough storage/RAM.

HOW TO TEST
1. Upload this folder to a trusted HTTPS static host (a parent/guardian can help with hosting).
2. Open its HTTPS address in Chrome on Android.
3. Open Chrome's menu and choose 'Install app' or 'Add to Home screen' if offered.
4. Open the installed app once while online; then its cached starter interface can work offline.

This prototype does not connect to WhatsApp and does not automate a WhatsApp account.
